

# 🚀 DocMind Enterprise

AI-powered internal document assistant built using **FastAPI + LangChain + Ollama + ChromaDB**.

## 📌 Features

✅ Ask questions from company PDFs  
✅ Local AI model (Ollama)  
✅ FastAPI Web Interface  
✅ Chat History  
✅ Secure Offline Processing  
✅ No OpenAI Billing Needed  

---

## 🛠️ Tech Stack

- Python
- FastAPI
- LangChain
- Ollama
- ChromaDB
- HTML / CSS
