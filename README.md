

# 🚀 DocMind Enterprise And RAG

AI-powered internal document assistant built using **FastAPI + LangChain + OpenAI + ChromaDB**.

## 📌 Features

✅ Ask questions from company PDFs  
✅ OpenAI
✅ FastAPI Web Interface  
✅ Chat History  
✅ Secure Offline Processing
